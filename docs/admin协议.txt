1、登录 /admin/login
    请求: {"userName":"1", "passWord":"1"}
    响应：{"errorCode":0, "userName":"1", "serverTime":"12313465131", "level":2147483647,"roomCardNum":0, "authorization":"13rqeasdasd1ws"}
    备注：
        1、userName：账号(测试账号：admin)
        2、passWord：MD5("123456")
        3、serverTime：当前服务器时间戳
        4、level：等级(1、普通管理员  2、精英管理员  2147483647、超级管理员)
        5、roomCardNum：当前房卡数
        5、authorization：通信令牌(消息头中"Authorization"属性的值设置为此值)

6、获取操作日志 /admin/getOperateLogs
    请求: {"page": 1, "maxperpage": 10, "startTime": 0, "endTime": 0, "operateType":1, "operater": "admin"}

        3、page：当前页数

13、获取房卡消耗记录(获取俱乐部也是此接口) /admin/getRoomCardCostRecords
        请求: {"page":1,"maxperpage":10,"type":1,"timeType": 1,"zeroTime": 1, "arg": "abc", "clubModel":1}
        响应：{"errorCode":0, "total": 1, "array":[{"ppk":"1","nickName":"1","avatarUrl":"http://","costRoomCardNum":1,"roomCardNum":1,"phoneNumber":"1","clubKey":"1","clubName":"1","clubOnlineNum":1,"clubTotalNum":1,"clubFreeRoomCardTimes":[0,0],"clubModelLimit":1},...]}
        备注：
            1、page：当前页数
            2、maxperpage：每页最大记录数
            3、type：类型(1、玩家  2、俱乐部)
            4、timeType：时间类型(1、日  2、周  3、月)
            5、zeroTime：对应timeType的零点时间
            6、arg：指定查询参数(名称或id字符串 此参数可传可不传)
            7、ppk：玩家唯一标识
            8、nickName：玩家昵称
            9、avatarUrl：玩家头像地址
            10、costRoomCardNum：消耗房卡数
            11、roomCardNum：玩家当前房卡数
            12、phoneNumber：电话号码
            13、clubKey：俱乐部唯一标识
            14、clubName：俱乐部名称
            15、clubOnlineNum：俱乐部在线人数
            16、clubTotalNum：俱乐部总人数(为0时该俱乐部已删除)
            17、clubFreeRoomCardTimes：房费免费时间段([0,0] 开始时间戳,结束时间戳)
            18、clubModelLimit：模式权限(取此值的对应位数的二进制(0、亲友圈  1、联盟),如果为0表示无权限 为1表示有权限)
            19、clubModel：俱乐部模式(0、亲友圈  1、联盟  作为请求参数时可传可不传, 最为返回参数时表示当前俱乐部模式)

14、获取用户列表 /admin/getUsers
    请求: {"page": 1, "maxperpage": 10, "arg": "123", "type" : 1}
    响应：{"errorCode":0,"total":12,"users":[{"ppk":"", "type":0, "createTime":0,"loginTime":0,"loginType":1,"nickName":"","avatarUrl":"","bindInfos":[{"type" : 1, "key" : "12314"},...], "robotInfo" : {"playableGames":[{"area": 1, "gameType": 1, "baseNumAreas":[[100,200],[300,500]]},...], "playableTimes":[[1,2],[3,4],...]，"clubIds":["123456",...],"gamingClubKey":""}, "propertys":[{"1": 100},...],"playedGames":[1001,...]},...}
    备注：
        1、page：当前页数
        2、maxperpage：每页显示的记录数
        3、arg：查询参数(账号或ID或昵称(如果是ID需要在前面加上0000100000  保证为16位数) 账号或ID为精准查询、昵称为模糊查询 次参数可不传)
        3、total：总用户数
        4、type: 账号类型(0、玩家  1、陪玩  2、机器人)  请求时此参数可传可不传
        5、createType: 创建时类型(0、玩家  1、陪玩  2、机器人)
        6、createTime: 创建时间戳
        7、loginTime：登录时间戳
        8、loginType：最后一次登录类型(0、游客 1、微信 2、电话)
        9、bindInfos：绑定账号信息([{"type" : 1, "key" : "12314"},...]  type:类型(0、游客 1、微信 2、电话) key:账号)
        10、propertys：用户所有属性([{"1": 100},...])
        11、ppk：玩家唯一标识
        12、nickName：玩家昵称
        13、avatarUrl：玩家头像地址(当地址不带http时 需要使用固定的头像地址+"/"+此值)
        14、playedGames：已玩过的游戏列表(/1000为地区 %1000为游戏类型)
        15、robotInfo：机器人信息(此字段的值可能为空)
        16、area：地区
        17、gameType：游戏类型
        18、baseNumAreas：底分区间列表[[最低积分,最高积分],[最低积分,最高积分],...] 积分为字符串
        19、playableTimes：游戏时间区间列表[[开始时间戳,结束时间戳],[开始时间戳,结束时间戳],...]
        20、gamingClubKey：正在哪个俱乐部游戏中(为null就是不在)

        备注：用户所有属性
              "1"：金币
              "2"：钻石
              "3"：房卡
              "10"：性别
              "20"：游戏房间权限(此值为long型)、取此值的对应位数的二进制(1、麻将 5、跑得快 6、扯旋),如果为0表示无权限 为1表示有权限
              "1002"：玩家下线时间戳(0、在线 其余时间为离线时间戳)
        游戏地区：1、成都 4、金堂 5、隆昌 6、内江 7、简阳 8、冕宁 9、凉山
        游戏类型：1:麻将 4:考考 5:跑得快 6:扯旋 7:牛牛 8:金花
