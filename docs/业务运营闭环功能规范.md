# 管理后台业务运营闭环

## 必须提供的菜单

| 一级菜单 | 功能 | 禁止事项 |
|---|---|---|
| 会话安全 | 在线设备、踢线、封禁、会话撤销、异常登录 | 不显示 Token 原文 |
| 玩法发布 | 全国/省/市范围、版本、灰度、回滚、维护开关 | 不复制全国玩法到省市 |
| 亲友圈 | 成员游标分页、角色、冻结、房间、权限 | 不允许一次加载全体成员 |
| 房间审计 | 权威状态、事件、解散投票、异常恢复 | 不允许后台直接改牌局状态 |
| 账务对账 | 流水、房间扣费、退款、差异工单 | 不允许直接改余额 |
| 结算战绩 | 小结算、大结算、战绩一致性、重算预览 | 不允许覆盖原结算 |
| 回放调查 | 玩家视角、授权完整视角、访问原因 | 普通客服不可看暗牌 |
| 客服申诉 | 申诉、证据、处理、补偿单 | 客服不可直接发放资产 |
| 数据治理 | 保留、归档、销毁、法务冻结、注销 | 不允许绕过冻结删除 |
| 审计日志 | 操作人、权限、前后值、原因、Trace ID | 日志不可修改和删除 |

## 发布操作

1. 编辑人保存草稿并执行机器校验。
2. 生成不可变版本及内容摘要。
3. 发布后配置中心通知节点刷新。
4. 大厅按全国、省、市合并并返回目录版本。
5. 房间创建时锁定配置快照。
6. 回滚通过重新发布上一版本完成，不修改历史版本。

## 无代码操作目标

运营人员新增玩法只需选择牌类、玩法族、地区范围、房间方案、玩法规则、流程规则、算分规则、结算样式、UI 方案、协议方案和服务端方案。系统负责校验依赖、生成版本、灰度和回滚，不要求运营人员修改 Java、TypeScript 或数据库。
